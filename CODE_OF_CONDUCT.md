# Code of conduct

Lucy follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind and patient, assume good faith, and keep criticism about the work, not the
person. Harassment, insults and personal attacks aren't welcome in issues, pull requests,
discussions or anywhere else the project lives.

## Reporting

If someone's behaviour is a problem, contact the maintainer, [@AJMerr](https://github.com/AJMerr),
privately (the email on their GitHub profile). Reports are kept confidential. The maintainer may
edit or remove comments, and warn, or temporarily or permanently ban, anyone who breaks this code,
following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).

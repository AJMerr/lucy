# Lucy sprite (milestone 2)

The Tauri desktop overlay lives here: a transparent, always-on-top window that renders the
configured sprite pack and shows Lucy's replies in speech bubbles. It connects to `lucy-core`
over the local socket like any other front end.

Not scaffolded yet. See [ADR 0005](../../docs/adr/0005-sprite-tauri-and-packs.md) and
[ROADMAP](../../docs/ROADMAP.md).
